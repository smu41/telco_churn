# Telco 客戶流失

## 背景
Telco是一個虛構的電信公司，通過虛構的電信運營公司提供的住宅電話和網絡服務數據。去理解客戶流失為什麼對於電信運營商來說是重要的商業風險標準之一，因為它直接影響現在的營收，增加營收壓力，並削弱客戶的終身價值。因此，理解流失對於客戶的留存策略和穩定的增長是至關重要的。

## 目的
- 通過早期決策降低流失
- 更好的維護客戶終身價值
- 更有針對性的留存投入
- 強化分析，業務和運營之間的聯繫

## 數據集
數據集: <https://www.kaggle.com/datasets/alfathterry/telco-customer-churn-11-1-3>

### 數據描述
Telco客戶流失數據集包括了7043個虛擬客戶，家庭，生命週期，業務，產品組合，運營信號等50個維度組成的數據集。

- 客戶：

  年齡，老年人

- 家庭：

  家庭成員，家庭成員個數

- 生命周期：

  使用週期

- 業務：
  
  合同，電子賬單，支付方式，月費，總體費用，退款

- 產品組合：

  電話服務，多線，網絡服務，平均月下載量，在線安全，在線備份，設備防護，高級技術支持，流媒體（電視/電影/音樂），無線數據

- 運營信號：
  
  客戶狀態，滿意度分數，流失分數，流失分類，流失原因，客戶終身價值，地理區域
## 數據處理
1. 數據清理並規範列名，拆解關鍵商業字段（流失標籤，狀態等）
2. 拆解核心業務列並計算基礎KPI
3. 使用滿意度，流失分數，客戶終身價值，流失原因，分類，地理區域製作儀錶盤和細分
